# 주요 결정

- 2026-11-07 사용자 제공 카드 디자인 PDF를 적용한다. 현재 구현과 PDF 목록의 교집합인 저격·무효화·보호막·무장해제만 표시하고 지급한다. 사용자가 PDF에 없는 무장해제 무효화·손패 복구를 대국 지급에서도 제외하도록 확인했다. 최신 main의 네 카드 지급과 무장해제 적용 전 응답·공통 무효화 규칙을 유지한다. 후속 사용자 요청에 따라 카드 외형은 시작 화면과 같은 네온 테마로 적용한다. [카드 적용 기준](skill-card-design.md) 참고.

- 2026-11-07 온라인 스킬 대국의 흑·백은 연결 신원과 분리한다. 서버가 현재 대국의 선공에게 흑돌을 배정하고 재대결과 재접속 스냅샷에 같은 기준을 적용한다. 기본 스킬카드는 2라운드부터 두 라운드마다 플레이어별 턴 시작에 한 장 지급한다.

- 2026-11-07 온라인 스킬 턴 시간은 방 서버가 관리한다. 연결이 끊겨도 기한은 유지한다. 증강 선택과 방어 중에는 시계를 멈추고, 만료 시 서버가 고른 빈칸으로 공통 착수 규칙을 실행한다. 기존 무장해제는 적용 전 응답 하나로 합친다. 저격과 무장해제에 같은 무효화를 쓰며 추가 버리기 비용은 없다.

- 2026-11-07 온라인 증강은 1라운드부터 5라운드 간격으로 제공하고 양쪽의 선택이 끝나면 대국을 진행한다. 카드뭉치와 요새화부터 적용한다. 같은 증강을 중복 획득할 수 없으며 후보가 소진되면 선택을 건너뛴다. 후보와 보유 목록은 본인에게 보내고 요새화 효과는 판에 공개한다.

- 2026-11-07 로컬 대국은 기본 오목으로 제공한다. 온라인 스킬 대국은 돌 카드 3종과 기존 손패 카드 4종을 하나로 합쳐 각 카드에 같은 지급 확률을 적용한다. 저격 응답은 15초로 유지하고 무장해제는 방어자가 응답하거나 건너뛸 때까지 기다린다.

- 2026-11-07 저격·무효화·보호막은 기존 테스트 덱과 별도인 스킬 대국에 적용한다. 같은 TypeScript 전이가 로컬과 서버에서 실행된다. 응답 마감은 세션이 시각을 전달하고 서버는 연결과 무관하게 타이머로 확정한다. 온라인 스냅샷에 공개 대상·보호막·결과는 포함하고, 상대 손패·추가 비용으로 버린 카드·난수는 제외한다.

- 2026-11-07 온라인 수직 단면: 사용자의 온라인 2인 요청에 따라 `ws` + Node 24 게스트 방 서버를 연결했다. 기본/스킬 테스트 규칙을 직접 import하고 UI는 플레이어별 투영 상태를 사용한다. 두 명의 재대국 동의, 탭 내 토큰 복구, 기존 연결 교체를 지원한다. 영속 DB·호스팅·미확정 게임 규칙은 정하지 않았다. 현재 실행 계약은 [온라인 실행 가이드](online-play.md)를 따른다. 아래 온라인 초기 검토 항목은 이전 단계 기록이다.

- 화면 기반: React + TypeScript + Vite. 게임 기획에 따라 필요한 라이브러리를 추가한다.
- 구조: 가벼운 FSD를 사용하되 폴더는 실제 필요할 때 만든다. 공통 디자인 요소는 `src/design-system`에 둔다.
- 온라인 기능: 직접 운영하는 서버를 최소화한다. 관리형 서비스와 서버 측 검증 범위는 기획 확인 후 결정한다.
- 기본 판은 15×15이며 현재 개발 범위는 2인 개인전이다. 3인 대국은 향후 확장 후보로 둔다. 라운드는 두 플레이어가 각각 한 번씩 턴을 마친 단위다.
- 시작 시 별도 스킬카드 지급은 없고 자신의 턴 시작에 1장을 획득한다. 상세 규칙과 미결 사항은 `docs/game-spec.md`를 따른다.
- 미확정: 계정, 재접속, 온라인 서비스, 배포 대상 및 비용.
- 규칙 모듈은 순수 TypeScript로 두고 세션이 상태 보관과 통신을 맡는다. 화면은 표시용 상태와 명령으로 연결한다. 턴 전이와 방어 응답은 [규칙 모델 초안](game-rules-design.md)에 정리했다.
- 대국 모드가 5목·6목 중 기본 목표 길이를 정한다. 연속 줄의 전체 길이가 목표와 정확히 같을 때 승리한다. 선공은 세션에서 정하고 규칙 모듈에는 선공부터 정렬된 순서를 전달한다.
- 로컬 대국은 순수 규칙 모듈의 상태와 전이를 사용한다. 화면에서만 플레이어 ID를 돌 색으로 바꾸어 공통 오목판에 전달한다. 카드 풀이 확정될 때까지 턴 진입에서 카드 지급 신호를 생성한다.
- 카드 엔진은 기본 착수 전이를 재사용한다. 테스트 대국은 카드 순서와 난수 시드를 명시적으로 입력하며, 실제 대국의 카드 정책과 테스트 시나리오를 분리한다.
- 로컬 화면의 스킬 테스트 대국에서는 두 플레이어에게 같은 순서로 카드를 지급한다. 무장해제의 적용 전·후 응답, 무효화와 손패 복구를 사용하며 응답이 끝날 때까지 착수를 보류한다. 카드 순서와 효과는 테스트용이다.
- 온라인 초기 검토: [통신 제안](online-transport-proposal.md)에 서버 상태, 공통 규칙 호출·플레이어별 투영 경계, 요청 ID·게임 revision과 재접속 초안을 정리했다. 제품 계약은 합의 전이다. `ws`는 독립 로컬 실험에만 사용하며 제품 라이브러리·호스팅·DB·인증·게임 정책은 확정하지 않았다.
