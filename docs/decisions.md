# 주요 결정

- 화면 기반: React + TypeScript + Vite. 게임 기획에 따라 필요한 라이브러리를 추가한다.
- 구조: 가벼운 FSD를 사용하되 폴더는 실제 필요할 때 만든다. 공통 디자인 요소는 `src/design-system`에 둔다.
- 온라인 기능: 직접 운영하는 서버를 최소화한다. 관리형 서비스와 서버 측 검증 범위는 기획 확인 후 결정한다.
- 기본 판은 15×15이며 현재 개발 범위는 2인 개인전이다. 3인 대국은 향후 확장 후보로 둔다. 라운드는 두 플레이어가 각각 한 번씩 턴을 마친 단위다.
- 시작 시 별도 스킬카드 지급은 없고 자신의 턴 시작에 1장을 획득한다. 상세 규칙과 미결 사항은 `docs/game-spec.md`를 따른다.
- 미확정: 계정, 재접속, 온라인 서비스, 배포 대상 및 비용.
- 규칙 모듈은 순수 TypeScript로 두고 세션이 상태 보관과 통신을 맡는다. 화면은 표시용 상태와 명령으로 연결한다. 턴 전이와 방어 응답은 [규칙 모델 초안](game-rules-design.md)에 정리했다.
- 대국 모드가 5목·6목 중 기본 목표 길이를 정한다. 연속 줄의 전체 길이가 목표와 정확히 같을 때 승리한다. 선공은 세션에서 정하고 규칙 모듈에는 선공부터 정렬된 순서를 전달한다.
