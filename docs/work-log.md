# 작업 기록

## 턴 종료음 제거와 스킬음 보강 — 2026-11-07

- 사용자 피드백에 따라 로컬·온라인의 별도 턴 종료 효과음을 제거했다. 착수 및 승리 수에도 착수음 한 번만 재생하며 방어 만료 등 수동 조작 없는 상태 갱신은 무음이다.
- 스킬음은 기존보다 출력과 지속 구간을 늘리고 세 개의 음을 겹쳐 구분하기 쉽게 조정했다. 사용자 조작의 AudioContext.resume가 진행 중일 때 첫 효과음이 버려지던 경로를 수정했다. 250ms를 넘긴 오래된 요청과 음소거 전 요청은 재생하지 않는다.
- 검증: 테스트 48개, lint, build 통과. 시작 시 재생 활성화 경합, 음소거 중 활성화 완료, 지연된 활성화 후 재생 누적 방지와 제거된 구 버전 턴 종료 이벤트 무음을 검사했다. 브라우저 OfflineAudioContext로 실제 합성 파형을 렌더링해 스킬음 RMS 약 0.062, 유효 출력 약 223ms, peak 약 0.283을 확인했다(착수음 RMS 약 0.012). 주관적 청음 평가와 별개로 출력 증가를 검증했다.
- 개발용 `tests/audio-preview.html`은 Vite에서 파형 측정 및 두 효과음 미리듣기를 제공한다. 로컬 8790 미리보기 서버를 재시작했으며 GitHub 푸시/공개 Render 배포는 수행하지 않았다.

- 검증: 테스트 47개, lint, build 통과. 효과 이벤트 분류·승리 수의 턴 종료·스킬/방어·중복/구 게임 이벤트 무시와 실제 WebSocket의 양쪽 효과 전송·실패/복구 무음을 검증했다. 브라우저에서 효과음 버튼·음소거 저장/복원과 로컬 스킬/방어·키보드 착수를 확인했으며 콘솔 오류가 없었다.

## 저격·무효화·보호막 정식 대국 — 2026-11-07

- 로컬·온라인의 **스킬 대국**에서 세 카드가 턴 시작에 같은 확률로 한 장씩 지급된다. 저격과 보호막은 착수 전에 종류마다 한 장씩 쓸 수 있다. 무효화는 방어자가 고른 다른 카드 한 장을 함께 소모한다.
- 저격에 15초 방어 창을 열고 무효화, 보호막, 돌 파괴 순으로 처리한다. 보호막은 한 번 막으면 사라지고 부여한 라운드에서 네 라운드가 지난 시점에 만료된다. 저격으로 장목이 정확히 5목·6목이 되면 돌 소유자가 승리한다. 서버는 재접속에도 마감을 유지하고 본인 손패와 공개 상태만 보낸다.
- `npm test` 43개, `npm run lint`, `npm run build`, `git diff --check` 통과. Chrome 1440px·390px에서 로컬 대상 선택과 무효화 비용을 확인했고, 브라우저 두 탭에서 온라인 방어 중 새로고침, 남은 시간 유지와 착수 동기화를 확인했다.
- 이번 세 카드의 확인 질문은 모두 해결했다. 다른 카드·증강과의 연쇄 효과는 후속 기획이다. GitHub 앱의 기능 이슈 생성 요청은 403을 반환했다.
