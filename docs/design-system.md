# 디자인 시스템

## 목적과 현재 상태

시작 화면은 네온 전략 게임 방향의 기본 시안이다. `features/lobby`에 짙은 청색 배경·청록/보라색 강조·장식용 벡터 오목판을 두고, 헤더 색상은 헤더 내부 변수로 한정한다. 온라인·로컬 진입 링크는 기존 대국 영역으로 이동한다. 대국 설정과 손패·도감에도 같은 네온 테마를 적용한다.

일관되고 접근하기 쉬운 UI를 재사용할 수 있도록 디자인 기준을 관리한다. 시작 화면과 대국 UI는 `src/design-system/tokens.css`의 색상, 간격, 포커스와 조작 영역 토큰을 공유한다. `neon-game.css`에서 어두운 청색 바탕과 청록·보라 강조색을 적용하며, 오목판의 흑·백돌은 윤곽으로 구분한다.

## 공통 컴포넌트 사용법

- `<Button onClick={handleClick}>대국 시작</Button>`은 주요 동작에 사용한다. 보조 동작에는 `variant="secondary"`를, 실행할 수 없는 동작에는 `disabled`를 지정한다. 기본 타입은 `button`이며 폼을 제출할 때는 `type="submit"`을 명시한다.
- `<MenuNavigation label="주 내비게이션" items={[{ href: '#welcome', label: '시작 화면' }]} />`처럼 실제 목적지가 있는 링크를 전달한다. Tab으로 링크 사이를 이동하고, Esc를 누르면 메뉴가 닫히며 메뉴 버튼으로 포커스가 돌아온다.

## 대국 UI 사용법

- 상단의 **효과음 켜짐/꺼짐** 버튼은 로컬·온라인 대국에 함께 적용되며 브라우저에 선택을 저장한다. 착수는 짧은 목재 타격음, 스킬 사용은 더 크고 지속되는 상승음으로 구분한다. 착수와 겹치는 별도 턴 종료음은 사용하지 않는다. 스킬 선택이나 대상 선택만으로는 재생하지 않고 확정된 행동에만 재생한다.
- 효과음은 Web Audio로 합성한다. 첫 사용자 조작에서 오디오를 활성화하며, 해당 활성화가 진행 중이면 최대 250ms 이내의 요청만 완료 후 재생한다. 음소거·브라우저 재생 제한 중에는 오래된 이벤트를 쌓아 뒤늦게 재생하지 않는다. 소리는 기존 텍스트·턴·방어 안내를 보조한다.

- `GomokuBoard`에 좌표별 `cells`와 선택 가능 여부를 반환하는 `isSelectable(point)`, 선택을 전달하는 `onSelect(point)`를 넘긴다. 좌표는 0부터 시작하는 행·열이며, `boardCoordinate(point)`로 `H8` 형식의 키를 만든다. 셀은 흑·백돌, 최근 착수, 승리 줄과 공개 효과 표식을 받는다. `walls`는 공개된 선분만 받는다. 읽기 전용 판은 `onSelect`를 생략한다.
- 판은 Tab으로 들어간 뒤 방향키, Home·End로 이동한다. Enter·Space로 교차점을 선택한다. 모바일의 **판 확대**를 켜면 넓어진 교차점을 스크롤하며 조작할 수 있다.
- `Modal`은 제목과 설명, 본문, 동작 버튼을 받는다. 브라우저의 모달 포커스 관리를 사용하며, Esc로 닫은 뒤 호출 버튼으로 돌아간다. 여러 후보 중 하나를 고르는 경우 `GameChoiceModal`을 사용한다. 인라인 선택에는 `GameChoices`를 사용한다. 선택 불가 후보는 `unavailable`에 이유를 넣는다.
- `PlayerStatus`에 돌 색, 현재 턴과 개인별 목표를 넘긴다. `SkillHand`에 화면에서 볼 수 있는 카드와 상세 열기 콜백을 전달한다. `GameNotice`는 진행·경고·오류 메시지를 텍스트로 안내하며 즉시 읽어야 하는 오류에는 `alert`를 지정한다.
- 온라인 스킬 대국에서는 `SkillCardPicker`에 소유자 돌 색과 현재 손패, 선택 ID, 선택 콜백을 넘긴다. `SkillCardFace`는 손패와 도감에 공통으로 쓰며 이름·종류·효과 설명, 선택적으로 보유 수와 사용 불가 이유를 글로 표시한다. `artwork`에 `snipe`, `nullify`, `shield`, `disarm` 중 하나를 지정하면 공통 SVG 삽화를 표시한다. 카드 선택은 라디오 그룹이며 실제 사용은 별도 확인 버튼으로 요청한다.
- 온라인 스킬 대국에서는 오목판 오른쪽에 본인 손패와 상대 손패 장수를 표시한다. 좁은 화면에서는 판 아래로 옮긴다. 판 위에는 내 턴·상대 턴과 방어 가능 여부를 표시하며, 방어할 수 있을 때는 손패로 이동하는 링크를 제공한다.

현재 카드 디자인은 시작 화면과 같은 네온 테마를 사용한다. 어두운 바탕에 공격은 보라색, 방어는 청록색 아이콘과 이름을 표시한다. 효과 설명은 마우스를 올리거나 키보드 포커스 또는 i 버튼으로 확인하며 Escape로 닫는다. 흑·백은 테두리, 글자와 돌 모양으로 구분한다. 대국 설정 역시 같은 테마로 표시하며 좁은 화면에서는 한 열로 배치한다. 저격 그림은 상대 색 돌, 보호막 그림은 내 색 돌이다. 이전 생성 이미지 파일은 보존하되 현재 카드에서 참조하지 않는다.

카드 도감은 PDF에 있고 구현된 저격·무장해제(공격), 무효화·보호막(방어) 4종만 보여 준다. PDF의 나머지 31종은 보류 목록에 이름만 표시한다. 카드 원문 기획 목록은 `src/features/skill-catalog/cards.ts`에 보존한다. 자세한 대응은 [카드 적용 기준](skill-card-design.md)을 따른다.

PDF에 없는 무장해제 무효화·손패 복구는 지급과 사용을 보류한다. PDF의 복구는 돌 복구로 미구현이며 손패 복구와 구분한다. 무효화 설명에는 현재 저격 방어용임을 표시한다. 무장해제 응답은 **확인하고 계속**으로 진행하며, 저격의 **방어하지 않기**와 15초 제한은 유지한다.

정식 스킬 대국은 도감과 같은 네 가지 벡터 삽화를 손패에 재사용한다. 대상 선택은 공통 오목판에서 하고 보호막은 공개 표식으로 표시한다. 방어 응답 중에는 착수를 막고 저격의 남은 시간과 버릴 카드 선택을 안내한다.

개발 연동 시 규칙·세션에서 받은 합법 좌표, 턴·라운드, 개인 목표, 카드 사용 가능 사유, 증강 후보, 응답 요청, 승리 줄과 연결 상태를 UI에 매핑한다. 착수·카드·응답 확정은 명령으로 보낸다. 상대에게 보이지 않는 손패·지뢰·은신 정보는 서버에서 걸러낸 뒤 공개 뷰만 전달한다. 방어 타이밍·제한 시간, 증강 지급 시점, 버프·특수 카드와 조우자의 효과는 기획이 확정되면 연결한다.

## 작업 경계

- 디자인 채팅: 시각 방향, 토큰, 공통 UI 컴포넌트 및 상태, 접근성, 사용법을 관리한다.
- 개발 채팅: 게임 규칙과 데이터, 온라인 상태를 UI에 연결하고 실제 기능을 검증한다.
- 공통 컴포넌트를 바꾸면 사용법과 영향을 받는 화면을 함께 확인한다. 컴포넌트에 게임 규칙이나 통신을 직접 결합하지 않는다.

## 설계 시 확인할 항목

키보드 조작과 포커스, 명도 대비, 색상 외 상태 표시, 모바일 터치 영역, 반응형 레이아웃, 모션 감소 설정, 로딩·오류·연결 상태를 고려한다. 구체적인 색상·타이포그래피·컴포넌트 규격은 디자인이 정해지면 이 문서와 실제 코드에 반영한다.
